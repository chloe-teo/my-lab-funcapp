# Azure Functions OpenTelemetry Deployment Lab

This project was cloned from the [Azure Samples functions-quickstart-dotnet-azd-otel repository](https://github.com/Azure-Samples/functions-quickstart-dotnet-azd-otel).

It is a sample application for testing:

- OpenTelemetry integration with .NET isolated Azure Functions
- Azure Functions deployment workflows
- Flex Consumption plan deployment using an Azure Pipelines zip package

The application source is in [`src`](src), and the Azure Pipelines definition is [`azure-pipelines.yaml`](azure-pipelines.yaml).
